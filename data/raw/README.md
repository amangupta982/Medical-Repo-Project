# Raw Data — Data Dictionary

This directory contains **real calibration datasets** that ground the synthetic
PHC-level operational data in actual published sources. Each file's provenance
and license are documented below.

## Files

### `india_health_centres_district.csv`
| Field | Description |
|---|---|
| **Source** | Rural Health Statistics, Ministry of Health & Family Welfare, India (data.gov.in) |
| **License** | Government Open Data License – India (GODL) |
| **Scope** | All 30 districts of Karnataka |
| **Columns** | `district`, `state`, `sub_centres`, `phcs`, `chcs`, `sub_district_hospitals`, `district_hospitals`, `population_2011`, `area_sq_km` |
| **How used** | Grounds the seed's PHC-per-district counts and catchment population ranges. The project uses 10 representative districts with 6 PHCs each — a deliberate subset for demo responsiveness. |

### `dengue_cases_india.csv`
| Field | Description |
|---|---|
| **Source** | NCVBDC (National Centre for Vector Borne Diseases Control) annual reports; also available via Kaggle (`jadhavpranav/dengue-cases-in-india`) |
| **License** | Public government data / Kaggle dataset terms |
| **Scope** | State-wise dengue cases and deaths, 2017–2023 |
| **Columns** | `Year`, `States/UTs`, `Cases`, `Deaths` |
| **How used** | Calibrates outbreak magnitude and year-over-year trend assumptions in the seed's outbreak event generator. |

### `idsp_seasonal_reference.json`
| Field | Description |
|---|---|
| **Source** | Published IDSP weekly surveillance analysis (Indian J. Community Medicine, 2024); WHO Global Health Observatory; BMC Medical Informatics 2026 bed-occupancy study |
| **License** | Academic / Open Access |
| **Contents** | Seasonal disease curves (malaria/dengue, GI/waterborne), annual dengue trend, bed occupancy dynamics, supply chain parameters |
| **How used** | Provides the exact `seasonal_multiplier()` parameters, bed-occupancy mean/std bounds, and lead-time distributions used in `backend/app/database/seed.py`. Every number traces back to a cited source. |

## Important Note

**The daily PHC-level operational data (inventory, consumption, footfall, staff
attendance) is NOT sourced from any of these files.** That layer is synthetically
generated by `seed.py` using these real-world distributions as calibration inputs.
This is explicitly stated in `docs/DATA_SOURCES.md`.
